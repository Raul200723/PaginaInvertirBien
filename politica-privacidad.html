Política de privacidad

Última actualización: 2026

En InvertirBien.es respetamos la privacidad de nuestros usuarios y nos comprometemos a proteger cualquier información personal que pueda recopilarse durante la utilización del sitio web. Esta política explica qué información puede recopilarse, cómo se utiliza y qué derechos tienen los usuarios conforme a la normativa vigente, incluido el Reglamento General de Protección de Datos (RGPD) y la legislación española que resulte aplicable.

1. Responsable del tratamiento

Responsable del sitio web: InvertirBien.es Correo electrónico de contacto: contacto@invertirbien.es Si todavía no dispones de un correo específico, sustituye esta dirección por la que utilices para atender consultas relacionadas con la privacidad.

2. Datos que pueden recopilarse

Dependiendo del uso que el usuario haga del sitio web, podrán recopilarse los siguientes datos:

  • Nombre (si el usuario lo facilita).
  • Dirección de correo electrónico.
  • Información enviada mediante formularios de contacto.
  • Dirección IP.
  • Información técnica del navegador.
  • Dispositivo utilizado.
  • Cookies y tecnologías similares.
  • Datos estadísticos de navegación.

En ningún caso se solicitarán datos personales innecesarios para la finalidad del sitio web.

3. Finalidad del tratamiento

Los datos podrán utilizarse para:

  • Responder consultas realizadas por los usuarios.
  • Mejorar el funcionamiento del sitio web.
  • Analizar estadísticas de uso.
  • Garantizar la seguridad del sitio.
  • Cumplir obligaciones legales.
  • Mostrar publicidad cuando corresponda.

4. Base jurídica

El tratamiento de datos personales se realizará cuando exista una base legal que lo permita, como por ejemplo:

  • Consentimiento del usuario.
  • Ejecución de una solicitud realizada por el usuario.
  • Cumplimiento de obligaciones legales.
  • Interés legítimo del responsable del sitio web.

5. Conservación de los datos

Los datos personales únicamente se conservarán durante el tiempo necesario para cumplir la finalidad para la que fueron recopilados o mientras exista una obligación legal de conservación.

6. Destinatarios de los datos

Con carácter general no se venderán ni cederán datos personales a terceros, salvo cuando exista obligación legal o sea necesario para prestar un servicio. El sitio web puede utilizar proveedores tecnológicos para alojamiento web, estadísticas, protección frente a ataques o prestación de servicios relacionados con su funcionamiento.

7. Google AdSense

Este sitio web puede utilizar Google AdSense para mostrar anuncios. Google y sus socios pueden utilizar cookies para personalizar la publicidad en función de las visitas anteriores del usuario a este u otros sitios web. Los usuarios pueden consultar información adicional sobre el funcionamiento de la publicidad personalizada y gestionar sus preferencias mediante las herramientas proporcionadas por Google.

8. Google Analytics u otras herramientas estadísticas

Este sitio web puede utilizar herramientas de análisis para conocer información estadística agregada sobre las visitas recibidas, páginas consultadas o dispositivos utilizados. Estos datos se emplean únicamente con fines analíticos y para mejorar el contenido del sitio web.

9. Derechos del usuario

Los usuarios pueden ejercer los derechos reconocidos por la legislación vigente, entre ellos:

  • Derecho de acceso.
  • Derecho de rectificación.
  • Derecho de supresión.
  • Derecho de oposición.
  • Derecho a la limitación del tratamiento.
  • Derecho a la portabilidad de los datos cuando resulte aplicable.

Para ejercer cualquiera de estos derechos podrá enviarse una solicitud al correo electrónico indicado anteriormente.

10. Seguridad

Se adoptarán medidas técnicas y organizativas razonables para proteger la información tratada y reducir el riesgo de accesos no autorizados, pérdida, alteración o divulgación de datos personales.

11. Enlaces externos

Este sitio web puede incluir enlaces a páginas de terceros. InvertirBien.es no es responsable del contenido, disponibilidad o políticas de privacidad aplicadas por dichos sitios web. Se recomienda revisar las políticas correspondientes antes de facilitar datos personales.

12. Menores de edad

Este sitio web está dirigido al público general. No se recopilan deliberadamente datos personales de menores de edad sin la autorización correspondiente cuando resulte legalmente exigible.

13. Cambios en esta política

Esta política de privacidad podrá modificarse para adaptarse a cambios legales, técnicos o de funcionamiento del sitio web. Las modificaciones serán publicadas en esta misma página.

14. Contacto

Si tienes cualquier duda relacionada con esta política de privacidad puedes ponerte en contacto a través del correo electrónico indicado anteriormente.

Importante: La información contenida en este sitio web tiene carácter exclusivamente educativo y divulgativo. No constituye asesoramiento financiero, fiscal, jurídico o de inversión personalizado.
